# 目标状态自动同步设计

## 规则

- 周目标和月目标共用同一套状态计算。
- 无关联待办：进度 0%，状态“未开始”。
- 有关联待办且平均完成率小于 100%：状态“进行中”。
- 有关联待办且平均完成率达到 100%：进度 100%，状态“已完成”。

## 触发

新增、编辑、删除待办以及更换关联目标后，回算涉及的新旧目标。每次数据刷新后也检查全部目标，让已有数据自动符合规则。

## 界面

周/月目标新建表单默认“未开始”，状态选项增加“未开始”。目标最终状态以关联待办自动回算结果为准。

## 验收

覆盖零关联、部分完成、全部完成、完成率回落及刷新时批量同步；保留现有云端写入兼容逻辑。
