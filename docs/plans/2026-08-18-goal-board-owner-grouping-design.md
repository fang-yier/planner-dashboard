# 周目标/月目标板块与负责人分组设计

日期：2026-08-18

## 目标

为周目标和月目标增加一个板块字段，并保留一个可编辑的负责人真实姓名；目标列表与仪表盘目标概览按板块分组，同时将仪表盘成员待办移动到周/月目标概览上方。

## 已确认约束

- 每个目标只绑定一个板块和一个负责人。
- 板块首批选项为：页面、推广、活动、会员、social、直播、其他。
- 负责人默认填入当前账号真实姓名，但允许手动修改。
- 目标卡片保留现有布局，仅在大标题右侧增加板块标签和负责人姓名。
- 成员待办继续按负责人分组，不改动其日期联动规则。
- 仪表盘中的周目标/月目标概览不展示已完成或已经过期的目标；管理页仍保留这些目标。
- 旧目标没有板块字段时归入“未分配板块”，不得影响旧数据展示和编辑。

## 数据模型

在现有目标对象上增加：

- `board: string`：板块名称。
- `owner: string`：负责人真实姓名；沿用现有负责人字段，编辑时默认当前账号姓名。

不新增表，不改变周目标/月目标现有 ID、状态、进度、周期和待办关联规则。

## 页面行为

### 周目标/月目标管理页

- 目标编辑弹窗增加“板块”下拉框。
- 负责人输入框保留，新增目标时预填当前账号真实姓名。
- 目标卡片按“板块 → 时间段”分组：周目标板块内部按周次分段，月目标板块内部按月份分段。
- 分组标题显示板块、时间段、目标数量和平均进度；目标卡片沿用现有卡片内容。
- 缺少 `board` 的历史目标放入“未分配板块”。

### 仪表盘

- 成员待办模块移动到周/月目标概览模块之前，位于 Banner 下方的第一张业务卡片。
- 周/月目标概览继续保留现有轮播和统计，但每个目标卡片按板块分组。
- 仪表盘概览过滤 `status === '已完成'` 的目标，以及目标周期结束日早于今天的目标；过滤发生在统计、分组和卡片渲染之前。
- 卡片标题右侧显示板块标签和负责人姓名。

## 实现边界

- 板块先使用前端固定常量，不做板块配置后台。
- Supabase 继续沿用现有目标表字段写入；若远端表缺字段，代码需保持本地模式和旧数据可读，并在部署前提示需要补充字段。
- 不重构 `app.js`，仅抽取必要的分组和展示辅助函数，降低改动风险。

## 验收标准

1. 新建周目标/月目标时，板块可选，负责人默认当前账号姓名。
2. 编辑旧目标时没有板块不会报错，可选择并保存板块。
3. 管理页和仪表盘目标概览均按板块分组。
4. 周目标管理页在每个板块内按周次分段，月目标管理页在每个板块内按月份分段。
5. 每张目标卡片大标题右侧显示板块标签和负责人姓名。
6. 仪表盘成员待办位于周/月目标概览上方，现有日期、完成率和分组行为不变。
7. 无板块历史数据显示在“未分配板块”。
8. JavaScript 语法检查、静态回归和浏览器验收通过。
