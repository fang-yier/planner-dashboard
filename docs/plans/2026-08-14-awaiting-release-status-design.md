# “待上线”待办状态设计

## 目标

在待办完整状态流中新增“待上线”，并确保添加、编辑、任务卡、按日进度看板、数据看板和成员负载统计使用一致的状态定义。

## 状态规则

- 顺序：未开始 → 进行中 → 审核中 → 待上线 → 已完成 → 打白工。
- 切换为“待上线”时，完成率自动设置为 90%。
- 切换为“已完成”时保持现有 100% 规则；切换为“未开始”或“打白工”时保持现有 0% 规则。
- 其他既有状态颜色不变。“待上线”使用独立的青蓝色视觉标识。
- 从进度看板拖入“待上线”列时，数据库同时保存状态和 90% 完成率。

## 展示与统计

- 待办添加/编辑窗口提供“待上线”选项。
- 仪表盘成员待办、每日待办等任务卡展示“待上线”标签。
- 每日进度看板增加“待上线”列。
- 数据看板任务状态分布、成员负载分布增加“待上线”计数与图例。
- “待上线”不计入已完成数量或完成率。

## 验证

- 静态回归测试验证所有状态入口包含“待上线”且状态联动为 90%。
- 浏览器验证下拉选择、任务卡标签、看板列及原有颜色。
- JavaScript 语法和 Git diff 校验通过后提交并推送。
