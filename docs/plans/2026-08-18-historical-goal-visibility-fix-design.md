# 历史目标可见性纠正设计

日期：2026-08-18

## 正确规则

- 仪表盘周/月选择器负责选择要查看的目标周期。
- 选择当前周/月时，仪表盘隐藏已完成目标。
- 选择历史周/月时，仪表盘展示该周期全部目标，包括已完成和现在已过期的目标。
- 左侧周/月目标管理页不跟随仪表盘筛选，始终展示全部历史。
- 左侧管理页继续按“板块 → 周次/月份 → 目标”分类。
- 左侧新建目标默认当前自然周/月，周期仍可在表单中修改。

## 根因

`dashboardGoalVisible` 无条件按今天过滤过期目标，导致历史周期中的所有目标被隐藏；管理页又被错误地绑定到仪表盘周期状态。

## 验收

1. 仪表盘选择历史周期可看到该周期已有和已完成目标。
2. 在历史周期从仪表盘新建目标后立即可见。
3. 当前周期仍隐藏已完成目标。
4. 左侧管理页恢复全部历史，并按板块和周期分类。
