# 仪表盘目标概览高度压缩设计

## 范围

只压缩仪表盘周目标/月目标轮播中的垂直空间。左侧周目标/月目标管理页和所有业务逻辑保持不变。

## 极简内容规则

- 板块区域保留头像和板块名称，取消完成统计、完成率数字和板块总进度条，改成一行小标题。
- 仪表盘目标描述紧跟目标名称同一行，以小号灰字显示并在空间不足时省略；目标管理页仍按原样显示。
- 每个目标压成两行：第一行显示名称、板块、负责人和完成率；第二行显示周期、优先级、状态和细进度条。

## 样式方案

仪表盘使用专用板块标题和目标内联进度条结构，并通过 `.dashboard-goal-slide` 限定样式。缩小轮播内边距、卡片间距、标签内边距和轮播圆点留白；按钮和周期输入框尺寸不压缩。

## 验收

确认极简结构只作用于仪表盘目标轮播，管理页描述、统计和进度保持原样，并通过现有目标和关联目标回归测试。
