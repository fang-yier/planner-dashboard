# 仪表盘与目标管理页周期同步设计

日期：2026-08-18

## 目标

让仪表盘和左侧周目标/月目标管理页共用同一套周次、月份选择状态，保证两处展示同一个周期的数据。

## 已确认行为

- 仪表盘与周目标管理页共用 `State.dashboardWeek`。
- 仪表盘与月目标管理页共用 `State.dashboardMonth`。
- 任一页面切换周期，另一页面立即沿用相同选择，刷新后继续保持。
- 左侧周/月目标页面增加与仪表盘相同的上一周期、选择器、下一周期、本周/本月控件。
- 左侧管理页只展示所选周期的目标，再按板块分组。
- 左侧管理页保留所选周期内的已完成目标；仪表盘继续隐藏已完成和已过期目标。
- 新建周目标默认使用当前所选周次，新建月目标默认使用当前所选月份。
- 成员待办、数据看板和趋势总览时间状态不受影响。

## 验收标准

1. 仪表盘选择周次后，周目标管理页展示同一周。
2. 周目标管理页切换周次后，仪表盘同步。
3. 月目标两处按相同规则同步。
4. 新建目标默认周期等于当前选择周期。
5. 管理页显示所选周期的已完成目标，仪表盘仍过滤已完成目标。
