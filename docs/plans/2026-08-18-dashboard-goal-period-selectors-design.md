# 仪表盘周/月目标周期选择设计

日期：2026-08-18

## 目标

仪表盘周目标和月目标概览分别支持选择周次和月份，并保持与成员待办相似的上一周期、周期选择、下一周期、当前周期操作方式。

## 已确认设计

- 周目标和月目标使用独立状态，不跟随成员待办日期。
- 周目标状态为 `dashboardWeek`，默认当前周；月目标状态为 `dashboardMonth`，默认当前月。
- 周目标控件：上一周、周次选择器、下一周、本周、添加周目标。
- 月目标控件：上一月、月份选择器、下一月、本月、添加月目标。
- 两个选择结果分别保存到 `localStorage`，切换轮播或刷新页面后保持。
- 周目标只展示 `goal.month === dashboardWeek` 的目标。
- 月目标只展示 `goal.month === dashboardMonth` 的目标。
- 已完成目标继续从仪表盘隐藏；选择历史周期时，未完成目标仍可展示。
- 成员待办的日期、数据看板周期和趋势总览逻辑完全不变。

## 交互与布局

- 周/月周期控件放在各自概览标题右侧、“添加目标”按钮之前。
- 控件尺寸、圆角和按钮风格复用成员待办日期控件。
- 周选择器显示 ISO 周格式，如 `2026-W34`；月选择器使用原生 `month` 输入。
- 空状态显示所选周期暂无进行中的目标，并提示历史完成项可在目标管理页查看。

## 验收标准

1. 周目标可前后切换周次、直接选择周次并回到本周。
2. 月目标可前后切换月份、直接选择月份并回到本月。
3. 周/月选择互不影响，并在刷新后保持。
4. 所选周期统计数量、平均进度、板块分组和目标卡片同步变化。
5. 成员待办、数据看板、趋势总览行为不变。
