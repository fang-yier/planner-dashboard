# 待办关联目标过滤设计

## 范围

只调整成员待办新增/编辑表单中的“关联目标”选项，不修改仪表盘、目标管理页、成员待办排版或目标数据。

## 规则

- 新建待办：显示本周及未来周的周目标、本月月目标中未完成且未过期的目标；未来月份不显示。
- 编辑待办：使用相同过滤规则，但始终保留该待办原先关联的目标，避免保存时意外解除历史关联。
- 账号资料记录（`__profile__`）永不显示。

## 实现

增加一个纯筛选函数，接收目标、原关联目标 ID、当前周、当前月和当天日期，返回是否可显示。`showTaskForm` 只调用该函数过滤 `State.goals`，其余表单逻辑保持不变。

关联目标选项同时显示目标周期：周目标使用 `【W34周目标】目标名称`，月目标使用 `【2026-08月目标】目标名称`。这只是下拉框展示格式，不修改目标真实名称。

## 验收

覆盖当前周/月进行中目标、未来周目标、未来月目标、历史周期目标、已完成目标、已过期目标、编辑时保留原关联目标，以及周/月选项标签格式。
